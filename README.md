# Дойняк — портфолио

Лендинг Виталика Дойняка в стиле Riverside (Refero): монохром + один акцент Studio Violet `#9671ff`.

## Стек

- `index.html` — разметка
- `styles.css` — токены и стили Riverside
- `script.js` — меню, фильтр проектов, форма, scroll-reveal

## Дизайн-система

- Inter + IBM Plex Sans (только лейблы в тёмных секциях)
- Pill-кнопки `border-radius: 300px`
- Один violet CTA на viewport
- Чередование white / midnight `#111111`
- Max-width `1200px`, section gap `80px`

## Запуск

Откройте `index.html` или любой static host (Netlify, Vercel, GitHub Pages).
